Sherlock Skill turns broad username-search hits into an evidence-backed,
reviewable public-source report.

## Highlights

- **Evidence-first reporting:** separates discovery signals, observations,
  inferences, confidence, and unresolved candidates.
- **Bounded pivot discovery:** follows distinctive public leads for at most two
  derived rounds and 12 checks by default.
- **Integrated identity assessment:** prevents weak clues from being propagated
  transitively into unsupported same-person conclusions.
- **Local standard-library scanner:** no external Sherlock command, API key,
  `pipx`, or third-party Python packages required.
- **Machine-readable evidence:** case reports include structured JSON alongside
  the Markdown investigation.
- **Safety boundaries:** designed for authorized public-source research, with
  no login bypass or private-data collection workflow.

## Quick start

```bash
git clone https://github.com/milddrunker/sherlock-skill.git
cd sherlock-skill

python scripts/username_analysis.py collect \
  --username example_user \
  --workspace .
```

Read [the documentation](https://github.com/milddrunker/sherlock-skill#readme)
for the full workflow, evidence model, and supported commands.
